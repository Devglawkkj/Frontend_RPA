# RPA Dashboard

Dashboard frontend para gestão de automações, agendamentos, execuções, integrações, usuários e logs.

## Visão geral

Este projeto é uma interface moderna em Next.js para acompanhar e administrar fluxos de automação de forma visual e organizada.

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS
- Radix UI
- React Query
- shadcn/ui

## Estrutura do projeto

- app/: páginas e estrutura principal da aplicação
- components/: componentes reutilizáveis e interfaces UI
- hooks/: hooks personalizados
- lib/: utilidades, helpers e configuração
- services/: integração com serviços e APIs
- types/: tipos compartilhados

## Requisitos

- Node.js 18 ou superior
- npm ou pnpm

## Instalação

```bash
npm install
```

## Execução local

```bash
npm run dev
```

A aplicação ficará disponível em http://localhost:3000.

## Build

```bash
npm run build
```

## Funcionalidades principais

- Dashboard com visão geral de operações
- Gestão de automações
- Cadastro e acompanhamento de agendamentos
- Visualização de execuções e logs
- Gestão de integrações e usuários

## Observações

Este projeto já inclui uma base para autenticação, navegação, administração e experiência de uso responsiva.
